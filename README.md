# Coordinate Quest

A GeoGuessr-style coordinate guessing game built with Next.js App Router, TypeScript, Tailwind CSS, Leaflet, and react-leaflet.

The player receives latitude and longitude coordinates, clicks the matching location on the map, then sees the correct marker, guessed marker, distance, and score. Each game has 5 unique random rounds for a maximum score of 25,000.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
